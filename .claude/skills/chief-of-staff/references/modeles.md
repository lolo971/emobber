# Modèles de livrables

## Briefing

```
# Briefing — <jour date>

**En bref :** <1 à 3 lignes : ce qui compte aujourd'hui>

## 3 priorités
1. <action> — pourquoi : <raison> — durée : <estimation>
2. …
3. …

## Agenda
| Heure | Objet | Avec | À préparer |
|-------|-------|------|------------|

## Boîte de réception
- **À traiter aujourd'hui** : <expéditeur — objet — action proposée>
- **À déléguer / réponse courte** : …
- **Pour info** : …
- **Ignorables** : <n> messages

## Échéances (≤ 48 h ou en retard)
| Engagement | Qui | Pour quand | Statut |
|------------|-----|------------|--------|

_Sources consultées : <liste>_
```

## Réunion

```
# Préparation — <objet> — <date heure>

**Résultat attendu :** <une phrase>

## Participants
- <nom> — <rôle> — enjeu : <ce qu'il veut>

## Contexte
- <dernier échange, décision, chiffre utile — source>

## À obtenir
1. …

## Questions à poser
- …

## Risques / points sensibles
- …
```

## Revue

```
# Revue — semaine <n°>

**En bref :** <1 à 3 lignes>

## Avancé
- …

## Glissé (et pourquoi)
- …

## Décisions prises
- …

## Engagements ouverts
| Engagement | Qui | Pour quand | Statut |
|------------|-----|------------|--------|

## Objectifs semaine prochaine
1. …
2. …
3. …

**Point d'attention :** …
```

## Relance

```
Objet : <sujet> — point d'étape

Bonjour <prénom>,

Je reviens vers vous au sujet de <engagement>, prévu pour le <date>.
Pouvez-vous me dire où vous en êtes et quand je peux compter dessus ?

Merci d'avance,
Laurent
```
