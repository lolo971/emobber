Tout le contenu se trouve dans le dossier formation/contenu/. Le code du site n'a jamais besoin d'être modifié pour ajouter une formation.

Les trois étapes

  1. Créer un dossier dans contenu/niveaux/, par exemple 04-mon-sujet.
  2. Y placer deux fichiers :
    • lecon.html : le texte de la leçon (paragraphes, listes, tableaux, images) ;
    • niveau.json : les questions du quiz.
  3. Déclarer le niveau dans contenu/parcours.json, à la position voulue dans la liste niveaux.

Format d'une question

{
  "id": "tva",
  "enonce": "Quel est le taux normal de TVA ?",
  "choix": ["5,5 %", "10 %", "20 %"],
  "bonnes": [2],
  "explication": "Le taux normal est de 20 %."
}
Les choix sont numérotés à partir de 0 : dans l'exemple, "bonnes": [2] désigne « 20 % », le troisième choix. Mettre plusieurs numéros dans bonnes transforme la question en choix multiple.

Mise en forme de la leçon

Trois encadrés sont disponibles : <div class="encadre"> pour une notion clé, <div class="exemple"> pour un exemple, <div class="attention"> pour un piège à éviter.

Un niveau peut aussi définir son propre seuil avec "seuil": 100 dans niveau.json.
